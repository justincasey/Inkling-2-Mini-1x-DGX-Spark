## Commands

`derive_meta.py` lists them; `run.sh` ran them in order, one GPU job at a time (wall time 342 s for the nine runs including the build, plus 14.5 s for the `inkling2_moe` rerun below):

```
export NODE=<node-3> LAB_SRC=<engine worktree at the pin> LANE=rexl3-inkling2-loop-pintests OPS_GREP=. OPS_LINES=5000
TEST_ENV="REXL3_INKLING2_DIR=<Small pack, read only>" PKG=gb-cuda scripts/ops_dev.sh test <BIN> ""   # BIN: inkling2_attn inkling2_attn_oracle inkling2_ops inkling2_dspark inkling2_moe_mixed inkling2_loop_vision
TEST_ENV="REXL3_INKLING2_DIR=<Small pack, read only> REXL3_INKLING2_RANK=2" PKG=gb-cuda scripts/ops_dev.sh test inkling2_moe ""
TEST_ENV="REXL3_INKLING2_DIR=<Small pack, read only>" PKG=gb-model scripts/ops_dev.sh test <BIN> ""   # BIN: inkling2_vision inkling2_loop_vision
```

(`inkling2_attn`, `inkling2_attn_oracle` and the Mini tests read the Mini pack through `REXL3_INKLING2_LOOP_DIR`, which `ops_dev.sh` sets; `REXL3_REQUIRE_GPU=1` is always set.)
