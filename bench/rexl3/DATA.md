# Data the bench tools need but this repository does not ship

`bench/rexl3/data/` is git-ignored (add `bench/rexl3/data/` to `.gitignore` if it is not there yet).

## GSM8K test split (`gsm8k.py`)

- File: `bench/rexl3/data/gsm8k_test.jsonl` (1,319 problems, one JSON object per line with `question` and `answer`; the
  answer ends `#### <number>`). About 730 KB, over the 200 KB the repository takes, so it is fetched, not copied.
- Source: OpenAI, `grade-school-math`, `grade_school_math/data/test.jsonl`; also published as the dataset `openai/gsm8k`.
  Licence: MIT (the upstream repository's `LICENSE`).
- Fetch (from the repository root; needs only curl):

```bash
mkdir -p bench/rexl3/data && curl -fL -o bench/rexl3/data/gsm8k_test.jsonl \
  https://raw.githubusercontent.com/openai/grade-school-math/master/grade_school_math/data/test.jsonl
```

`gsm8k.py --data PATH` takes any other copy (`.jsonl` or a JSON list of `{"question", "answer"}`).

The other sweep and needle tools need no data file: their filler is generated by `inkling_api.filler_sentences`.
